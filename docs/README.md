## 1. What is FinX

FinX is a local-first personal finance app with a glassmorphism / gold-line aesthetic. Data is stored on-device (IndexedDB). No backend, no database, fully portable, installable as a PWA.

## 2. Tech Stack

Vite + React 18 + TypeScript + Tailwind + Zustand + idb + Framer Motion + Recharts + Lucide. Hosted free on Vercel.
